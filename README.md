Labza Co - Construction Services Website

A modern, responsive website built for Labza Co, a construction service company.  
The website showcases construction services, company information, and provides an easy way for clients to request services and get in touch.

Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Responsive Design (Flexbox & Media Queries)


Features

- Modern and professional construction company landing page
- Fully responsive design for all devices
- Services section (construction offerings and solutions)
- About section introducing the company
- Projects/portfolio showcase layout
- Contact section with email and WhatsApp integration
- Smooth scrolling navigation
- Mobile-friendly navigation menu


 Project Purpose

This project was built for Labza Co to represent their construction services online and help potential clients easily understand their offerings and contact them for quotes or service requests.


Responsiveness

The website is fully responsive and optimized for:
- Mobile phones
- Tablets
- Desktop screens
